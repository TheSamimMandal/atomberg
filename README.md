Atomberg Smart IR Remote Controller

Atomberg Smart IR Remote Controller is a lightweight, fast, and modern Android application designed to provide a convenient remote-control experience for compatible Atomberg BLDC ceiling fans using a device's built-in infrared (IR) blaster.

The app focuses on simplicity, responsiveness, and offline operation. It provides a clean remote-style interface that allows users to control their compatible fan directly from their Android smartphone without requiring an internet connection, account, cloud service, or external remote-control hardware.

✨ Features

- 📡 Built-in IR blaster support
- 🌀 Atomberg BLDC fan remote control
- ⚡ Fast and responsive IR transmission
- 🔘 Power control
- 🎚️ Fan speed control
- 💡 LED control
- ⏱️ Timer functionality
- 🎛️ Dedicated remote-control interface
- 📱 Clean and modern Android UI
- 🚀 Lightweight and optimized for fast performance
- 🔌 Works completely offline
- 🚫 No advertisements
- 🚫 No login or account required
- 🚫 No cloud dependency
- 🔒 Designed with privacy in mind

🎨 User Interface

The application is designed to provide a simple and familiar remote-control experience while maintaining a modern Android look and feel.

The interface is optimized for quick access to frequently used fan controls, making everyday operation simple and convenient.

📡 Infrared Technology

The application communicates with compatible ceiling fans through the Android device's built-in IR transmitter.

It uses infrared remote-control commands to communicate directly with the fan, allowing the application to operate without Wi-Fi, Bluetooth, mobile data, or an external server.

📱 Device Compatibility

The application requires an Android smartphone with a compatible built-in IR blaster.

Compatibility with individual fan models and Android devices may vary depending on the available IR hardware and remote-control implementation.

🔐 Privacy & Offline Operation

Atomberg Smart IR Remote Controller is designed as an offline-first remote-control application.

The core remote-control functionality does not require:

- Internet connectivity
- User registration
- Cloud accounts
- Remote servers
- Personal user data
- Subscription services

The application is intended to keep the remote-control experience simple, private, and independent of online services.

⚡ Performance

The application is designed to remain lightweight and responsive while using minimal system resources.

The goal is to provide an instant remote-control experience without unnecessary background services or network operations.

🛠️ Project Goals

This project aims to provide:

- A modern alternative to a physical fan remote
- A simple Android-based IR remote experience
- Fast and reliable local control
- A clean and minimal user interface
- An offline and privacy-friendly experience
- An easy-to-use solution for compatible Atomberg BLDC fans
